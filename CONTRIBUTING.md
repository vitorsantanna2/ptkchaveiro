# Contribuindo

Obrigado por considerar contribuir com este projeto! Aqui estão algumas diretrizes básicas:

1. Fork o repositório e crie uma branch para a sua feature: `git checkout -b feature/nome-da-feature`
2. Mantenha commits pequenos e focados.
3. Execute os testes localmente antes de abrir um Pull Request.
4. Abra um Pull Request descrevendo as mudanças e referenciando issues relacionadas.

Se quiser ajuda para começar, abra uma issue com a tag `good first issue`.
